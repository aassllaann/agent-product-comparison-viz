## 🧪 测试验证

### 测试场景 1：游戏主机 → 显示器联动

**第 1 轮：**
```
用户: 想买个这种游戏主机玩黑神话悟空
推荐: Sony PlayStation 6 (￥4999)
生态建议: 配上一款高刷新率的电竞显示器，能让《黑神话：悟空》的每一帧动作都丝滑流畅...
```

**第 2 轮：**
```
用户: 给我推荐个配套的显示器
推荐: LG 27GR95QE (￥9999.0) | 240Hz | 2560x1440
生态建议: 你的PS6和Xbox性能这么猛，如果配上一台高刷、低延迟的4K显示器...
```

✅ **验证通过**：系统识别出用户已购游戏主机，推荐了高刷显示器，并生成符合场景的自然建议。

### 测试场景 2：商务轻薄本 → 耳机联动

**第 1 轮：**
```
用户: 经常出差，推荐个轻薄本
推荐: Huawei MateBook X Pro 2025 (￥12999)
```

**第 2 轮：**
```
用户: 再推荐个耳机搭配着用
推荐: Bose QuietComfort Ultra 2 (￥3599)
       Sony WH-1000XM6 (￥2799)
```

✅ **验证通过**：通过添加"出差"关键词，成功匹配到 `commute` 场景，推荐了降噪耳机。

### 测试场景 3：品牌过滤

```
用户: 我就要性能最强的英伟达显卡，不差钱
推荐: NVIDIA GeForce RTX 4060 Ti 16GB
      NVIDIA GeForce RTX 4060 Ti
过滤: AMD、Intel 品牌全部被正确排除
```

✅ **验证通过**：品牌过滤逻辑工作正常，LLM 正确解析"不差钱"并设置 max_price=999999。
